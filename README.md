<h1>✂️ Rock, Paper, Scissors Game</h1>
<p>
   This project is a graphical implementation of the classic <strong>Rock, Paper, Scissors</strong> game. It was developed as part of the <strong>Global AI Hub - Aygaz Bootcamp</strong>, demonstrating the use of Python and Tkinter to create an interactive and user-friendly game.
</p>

<h2>🛠️ Features</h2>
<ul>
   <li> Graphical interface developed using <strong>Tkinter</strong>.</li>
   <li> Displays game rules on a welcome screen.</li>
   <li> Allows the player to select their choice (Rock, Paper, or Scissors) against the computer's random choice.</li>
   <li> Updates and displays the scores after each round.</li>
   <li> Ends the game when either the player or the computer wins 2 rounds.</li>
   <li> Provides an option to play again or exit after the game ends.</li>
</ul>

<h2>⚙️ Technical Details</h2>
<ul>
   <li> Developed in <strong>Python</strong> using the <code>Tkinter</code> library for the graphical user interface.</li>
   <li> Incorporates Python's <code>random</code> module for the computer's choices.</li>
   <li> Implements dynamic window positioning for a user-friendly experience.</li>
   <li> Modular design with reusable methods for various game functionalities.</li>
</ul>

<h2>🚀 How to Use</h2>
<ol>
   <li> Clone or download the repository to your local machine.</li>
   <li> Ensure that Python is installed on your system.</li>
   <li> Run the script in any Python environment to start the game.</li>
   <li> Follow these steps in the game:</li>
   <ul>
      <li>Read the rules on the welcome screen and click "OK" to start.</li>
      <li>Choose "Rock", "Paper", or "Scissors" by clicking the respective button.</li>
      <li>The game will automatically calculate the result of each round and update the scores.</li>
      <li>The game ends when either the player or the computer wins 2 rounds.</li>
      <li>After the game ends, choose to play again or exit.</li>
   </ul>
</ol>

<h2>💡 Example Output</h2>
<p><strong>Gameplay:</strong></p>
<ul>
   <li>Player selects <code>Rock</code>, Computer selects <code>Scissors</code>.</li>
   <li>Result: "You win this round! (Computer chose: Scissors)"</li>
   <li>Player Score: 1, Computer Score: 0.</li>
</ul>
<p><strong>Game Over:</strong></p>
<p>"You won the game!" or "Computer won the game!" depending on the result.</p>
